Thin Film interactive models (PVD, CVD, ALD)

- PVD_model.html, CVD_model.html, ALD_model.html: self-contained pages. Double-click to open in any modern browser (no internet needed).
- template_source.html: shared source code (HTML + CSS + JavaScript). The MODE constant selects PVD, CVD or ALD.
- generate_models.py: regenerates the three pages from the template (python3 generate_models.py). Edit texts or colors inside it.

Illustrative 2D simulation, not a quantitative process simulator.
